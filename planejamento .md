# Planejamento do Sistema de Reembolso

## Capítulo 03: Requisitos do Sistema

### 1. Requisitos Funcionais (O que o sistema faz)
* **RF01:** Cadastro de despesas com valor, data e categoria.
* **RF02:** Upload de imagem do comprovante/recibo.
* **RF03:** Visualização do status da solicitação (Pendente/Aprovado).
* **RF04:** Painel do gestor para aprovar ou reprovar despesas.

### 2. Requisitos Não Funcionais (Como o sistema é)
* **RNF01:** Segurança através de login e senha.
* **RNF02:** Site responsivo para funcionar no celular.
* **RNF03:** Persistência de dados em banco de dados SQL Server.
